# 6단계 문서 그림

GitHub에서는 [작업정리.md](../작업정리.md)를 읽습니다. `badge-new.svg`·`badge-changed.svg`는 Markdown 표에 넣는 상태 배지이며, HTML에는 같은 색상·모양의 CSS 배지를 표시합니다. 큰 그림 네 개는 두 문서가 같은 SVG를 사용합니다.

`service-overview.drawio`는 편집 가능한 대표 구성도입니다. draw.io에서 **파일 → 열기 → 기기**를 선택해 열고 수정한 뒤 같은 이름의 SVG로 내보냅니다. 내보낸 SVG에는 오른쪽 위 범례까지 포함합니다.

Mermaid 원본은 `decider-sequence.mmd`, `bundle-sequence.mmd`, `rule-flow.mmd`입니다. 시퀀스는 실제 호출 순서이며 측정한 시간이 아닙니다. 렌더링 설정은 `mermaid-theme.json`, 이번 SVG 생성에 사용한 렌더러는 Mermaid 11.17.2입니다. Mermaid CLI를 사용하는 환경에서는 예를 들어 `mmdc -i decider-sequence.mmd -o decider-sequence.svg -c mermaid-theme.json -b white`로 렌더링할 수 있습니다. 이 CLI 명령 자체는 이번 작업에서 실행하지 않았습니다. 이번에는 렌더러의 `mermaid.render()`로 생성한 SVG에 제목·공통 범례 공간을 추가했습니다.

원본 `.mmd`에는 실제 흐름이, 내보낸 SVG에는 제목·범례도 들어 있습니다. 다시 렌더링한 뒤 상단에 제목과 우측 범례를 넣어야 현재 문서 디자인을 유지할 수 있습니다. 범례가 그림을 가리지 않도록 별도 상단 공간을 확보합니다.

상태 표시는 신규 초록 `#EAF7EE / #9FCDB0 / #276644`, 변경 파랑 `#EDF5FF / #AAC7E5 / #315A83`입니다. 문서 표와 그림의 배지는 테두리 1px·반경 7px·12px 글자·상하 1px/좌우 9px 여백으로 통일합니다. 배지에는 ‘신규’·‘변경’ 글자를 함께 표시합니다. 역할 구분에 사용하는 회색(기존·실행·파일), 보라(웹 서버), 황토(운영 계약), 빨강(거부)은 그림별 범례에서 별도로 설명합니다. 각 그림에는 실제 사용한 색상만 표시합니다.

`preview.html`은 로컬 SVG 네 개를 보여 줍니다. HTML과 이 폴더를 함께 복사하면 인터넷 없이 열람할 수 있습니다. `.drawio`나 `.mmd` 편집 도구를 설치하는 것은 그림 수정 때만 필요하며 본문·SVG 열람에는 필요하지 않습니다. Mermaid 렌더러를 최종 HTML에서 내려받거나 실행하지 않습니다.

`문서검증.json`은 PC 브라우저로 HTML을 직접 렌더링한 결과입니다. `검증-*.png`는 문서 상단·표·그림의 화면 확인 자료이며 실제 자료실 로그인 화면이나 심판 판정 화면이 아닙니다.

본문은 `../작업정리.md`, 열람용 문서는 `../작업정리.html`입니다. 본문 수정 후 Markdown을 HTML로 다시 변환하고 목차·로컬 그림 경로·배지 CSS를 유지합니다. 그림의 파일명과 상대 경로를 바꾸면 두 문서의 링크도 함께 수정합니다.
