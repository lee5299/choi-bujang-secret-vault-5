# 7단계 문서 그림

[작업정리.md](../작업정리.md)는 GitHub 본문, [작업정리.html](../작업정리.html)은 PC 열람 문서입니다. 두 문서는 같은 로컬 SVG 네 개를 사용합니다. [preview.html](preview.html)은 그림만 모아 보여줍니다.

대표 구성도는 service-overview.drawio입니다. draw.io에서 **파일 → 열기 → 기기**로 원본을 열고 수정한 뒤 service-overview.svg로 내보냅니다. 이 원본은 압축되지 않은 mxGraph XML이며 도형·연결선·문구·범례를 편집할 수 있습니다.

Mermaid 원본은 decider-sequence.mmd, bundle-sequence.mmd, rule-flow.mmd입니다. 설정은 mermaid-theme.json입니다. Mermaid의 render()로 SVG를 생성한 뒤 별도 상단 공간에 제목·우측 범례와 변경 파일 배지를 추가했습니다. .mmd는 실행 흐름의 원본이고 SVG는 문서용 디자인을 포함한 내보내기입니다.

Mermaid CLI를 사용하는 환경에서는 예를 들어 아래 명령으로 다시 렌더링할 수 있습니다. 이 CLI 명령 자체는 이번 문서 작업에서 실행하지 않았습니다.

```powershell
mmdc -i decider-sequence.mmd -o decider-sequence.svg -c mermaid-theme.json -b white
```

재렌더링 후에는 SVG 안의 우측 상단 범례와 변경 파일 배지를 다시 배치하고 원본 그림을 직접 확인합니다. 구성도도 SVG에 범례가 포함되도록 내보내야 합니다. 범례는 그림과 분리된 HTML 설명만으로 대체하지 않습니다. 시퀀스는 호출·응답의 순서이며 측정하지 않은 소요 시간을 나타내지 않습니다.

신규 배지는 배경 #EAF7EE / 테두리 #9FCDB0 / 글자 #276644, 변경 배지는 #EDF5FF / #AAC7E5 / #315A83입니다. 테두리 1px·반경 7px·글자 12px·상하 1px/좌우 9px 여백을 사용합니다. ‘신규’·‘변경’ 글자가 있으므로 색상만으로 구분하지 않습니다. 표의 배지는 항상 기존 역할 칸에 둡니다.

다른 역할 색상은 회색(기존 부품·실행·파일), 보라(기존 웹 서버), 황토(계약·미연결), 빨강(추가 확인 결정)입니다. 그림마다 실제 사용한 색상만 우측 상단의 같은 디자인 범례로 설명합니다. 구성도에서 기존 웹 서비스와 운영 엔진의 미연결 경계를 구분합니다.

HTML에는 외부 스크립트·폰트·Mermaid 렌더러가 없으며 .mmd를 실행하지 않고 SVG를 읽습니다. 7 폴더와 diagrams 폴더를 함께 복사하면 인터넷 없이 본문과 그림을 봅니다. 프로젝트 코드 링크를 열려면 전체 저장소를 함께 보관하고 고정 커밋 링크에는 인터넷이 필요합니다.

문서검증.json은 Chrome에서 문서·SVG를 직접 렌더링한 검증 메타데이터입니다. 화면 확인 PNG는 로컬 local-only/stage7-doc-qa/에 보관하며 GitHub에 올리지 않습니다. 이 자료는 문서 화면 확인이며 자료실·심판 시험이 아닙니다.

본문 수정은 ../작업정리.md에서 하고 HTML을 다시 생성합니다. 그림 원본을 수정하면 대응 SVG도 갱신하며 두 문서의 상대 경로와 목차를 함께 확인합니다.
