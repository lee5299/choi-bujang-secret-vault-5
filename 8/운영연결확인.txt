8단계 운영 판정기 연결 확인 요청안 (전송하지 않음)

현재 학생 요청 계약 aleph.decision.v1의 18개 필드와 응답 다섯 항목을 유지했습니다.
자료 API에는 개인 메모 소유자 검사와 저장된 강사 권한 검사 코드를 작성했습니다.
판정기의 자원 권한표 연결에는 운영 측 확인이 필요합니다.

확인이 필요한 항목
1. 학생 decide(request)가 실행되는 서버와 공식 설정 화면의 위치.
2. 서버 전용 ALEPH_RESOURCE_POLICY_JSON 환경변수를 그 실행 환경에 제공할 수 있는지.
   지원되지 않는다면 운영 측에서 제공하는 권한표 전달 방식과 계약.
3. 엔진의 가명 subjectId와 Supabase 사용자 UUID를 연결하는 검증된 관리자 절차.
   UUID를 subjectId로 그대로 쓰거나 임의 변환하지 않습니다.
4. 사용자에게 연결된 검증 deviceId의 공식 조회·승인 절차.
5. 실제 classId·projectId·service·policyRevision과 경로 접두사(/notes 또는 /api/notes).
6. allowedReasonCodes에 등록된 자원 권한 거부 코드.
7. 새 메모 UUID와 기기 변경·승인 회수 후 정확한 경로 권한표 갱신 절차.

안전한 전달 방식
- 필요한 것은 공식 관리 화면의 주소와 연결 방법입니다.
- 비밀번호·토큰·개인키·실제 사용자 값·메모 본문을 채팅, 이메일, Git에 보내지 않습니다.
- 운영자가 실제 값을 공식 서버 비밀 설정란에 직접 입력합니다.
- 가상 fixture의 사용자·기기·거부 코드는 운영 설정에 넣지 않습니다.

권장 기본 정책
- 이 자료실 로그인 사용자의 강사 공지 읽기.
- 활성 강사의 공지 추가 및 자기 공지 수정·삭제.
- 자기 메모 목록·추가와 정확한 UUID 경로의 자기 메모 읽기·수정·삭제.
- 다른 사용자·기기·동작·경로 또는 설정 누락은 거부.

현재 운영 값과 지원 여부를 확인하지 않았습니다.
이 파일은 준비한 요청안이며 외부 운영자에게 보내지 않았습니다.
