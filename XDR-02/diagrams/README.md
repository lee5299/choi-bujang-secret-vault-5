# XDR-02 다이어그램 원본과 이미지

2026-10-12 문서 그림을 정리했습니다. 프로그램·DB·XDR 결과·배포는 변경하지 않았습니다.

## PC에서 보기

전체 문서는 상위 폴더의 **작업정리.html**을 더블클릭하면 브라우저에서 볼 수 있습니다.
그림만 모아 보려면 이 폴더의 **preview.html**을 더블클릭합니다.
SVG 크게 보기로 원본 크기를 확인하고 브라우저 확대 기능을 사용할 수 있습니다.
HTML은 같은 폴더에 보관된 그림을 읽으며 외부 스크립트나 CDN을 호출하지 않습니다.
문서와 그림을 다른 PC로 옮길 때는 **XDR-02 폴더 전체**를 함께 복사합니다.
다른 프로그램 코드로 가는 링크는 원래 컴퓨터의 경로여서 다른 PC에서 열리지 않을 수 있습니다.

## 원본과 문서용 이미지

| 내용 | 수정 원본 | 문서용 이미지 |
| --- | --- | --- |
| 대표 서비스 구성 | service-overview.drawio | service-overview.svg |
| 로그인 요청 | login-sequence.mmd | login-sequence.svg |
| 메모 조회 | notes-sequence.mmd | notes-sequence.svg |
| XDR 실행 | xdr-sequence.mmd | xdr-sequence.svg |
| 차단 후보의 근거·만료 | rule-flow.mmd | rule-flow.svg |

대표 구성도는 draw.io XML 원본으로 관리합니다. 브라우저의 diagrams.net에서 **File → Open from → Device**로
service-overview.drawio를 열어 위치·문구·연결선을 수정하고 SVG로 내보낼 수 있습니다.
제공한 SVG에도 같은 draw.io 문서 데이터가 포함되어 있습니다.

시퀀스와 판단 흐름은 Mermaid 문법의 .mmd 파일로 관리합니다.
작업정리.md에는 SVG와 접을 수 있는 Mermaid 코드를 함께 넣었습니다.
원본을 수정하면 SVG와 HTML도 다시 생성해야 합니다. 자동 동기화하는 실시간 문서는 아닙니다.

## 시각 규칙

- 파랑: 화면·브라우저·사용자
- 보라: 서버·실행·판단 부품
- 초록: 인증·DB·생성할 규칙
- 회색: 파일·배포·보조 선
- 빨강: 거부·규칙 제외
- 연한 주황: 연결 범위 등 확인 주석

글꼴은 맑은 고딕을 우선 사용하고 Segoe UI와 sans-serif를 대체 글꼴로 둡니다.
흰 배경, 연한 도형 채움, 얇은 연결선, 짧은 문구와 충분한 간격을 사용합니다.
Mermaid 원본에는 공통 테마와 역할별 색상 설정이 들어 있으며 공통 설정은 mermaid-theme.json에도 보관합니다.
지원하는 테마 설정은 미리보기 도구마다 다를 수 있으므로 문서에서는 생성된 SVG를 사용합니다.

## 작성·확인 범위

Mermaid 11.17.2로 네 그림을 렌더링해 SVG를 생성했습니다.
대표 구성도의 draw.io XML 형식과 모든 SVG를 브라우저에서 확인했습니다.
다섯 그림의 한글·캔버스 밖 잘림·배치와 로컬 HTML의 그림 표시를 확인했습니다.
시퀀스는 호출 순서이며 실측 타이밍·성능 결과를 표시하지 않습니다.

문서 내용과 사용자 제안 표시를 보존했고, 그림 변경을 프로그램 보안 조치로 기록하지 않았습니다.
