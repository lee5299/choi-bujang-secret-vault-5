`npm.cmd run xdr:run -- privilege`

## 정상 이벤트 확인과 가상 재생

판단 모듈이 record로 고른 집합만 다시 세지 않고, 원본의 수준 2~3인 정상 구간 pv-18~26(단순 로그인·로그아웃·조회·정상 작업 등) 9건을 result의 경보 ID와 별도로 대조했습니다.
이 중 action=block인 경보는 0건입니다. 따라서 이번에는 오차단 원인 수정이나 코드 변경이 필요하지 않았습니다.

| 재생 대상 | 결과 |
| --- | --- |
| 명확한 공격 9건 | 9건 deny |
| 확인 대상 alert 8건 | 8건 기존 allow 유지 |
| 정상 9건 | 9건 기존 allow 유지, 거부 0건 |
| 개별 규칙 만료 9건 | 9건 만료 뒤 통과 |

재생의 기본 판정은 simulated_allow이며 실제 운영 접속과 구분합니다. 겹치는 근거의 개별 만료와 모든 규칙 만료 뒤 통과 검증은 제작 4 시험에 있습니다.
기본 live 모드는 가상 규칙을 적용하지 않습니다. 실제 계정·subjectId·세션 매핑과 운영 회수는 [TODO](../TODO.md)에 남겼습니다.
