만들기 5: 제작 5 · 시험 경보로 돌려 보기
npm run xdr:run -- exfiltration 를 실행해서 xdr/exfiltration/result.json 을 만들고, block·alert·record 건수와 정상 이벤트를 block 한 경우가 있는지 알려 줘. 정상 이벤트를 막았으면 그 경보 하나만 골라 원인을 고쳐 줘.

확인: result.json 의 counts 가 나오고, 정상 이벤트를 막은 경우가 없어야 합니다.

npm run xdr:run -- exfiltration 를 다시 실행해 result.json 을 갱신하고, 이번 변경을 「보너스 xdr-06 저장점」으로 커밋해 줘. 커밋 뒤 block·alert·record 건수를 한 줄로 보여 줘. 오류가 나면 첫 오류만 고쳐 줘.
