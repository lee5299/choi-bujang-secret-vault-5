## 연결과 안전 범위

respond.mjs는 원본 decide 결과를 재확인하고 유일한 경보 ID·목적지·시각·패턴이 맞는 block 후보만 규칙에 넣습니다. 규칙은 가상 목적지 하나에 한정하고 시작·15분 만료·근거 경보 ID를 기록합니다. 같은 목적지의 정상/애매 사건이 유효 기간에 있으면 후보를 제외합니다. 출발 IP나 계정 전체를 막지 않습니다.
기존 deny/step_up은 원형 그대로 반환하고 allow에만 추가 검사합니다. 가상 규칙을 운영 기본 모드에 적용하지 않습니다. 실제 엔진이 검증한 목적지 전달·규칙 조회·운영 거부 코드 등록 약속이 없어 실제 ZTNA 연결은 미완료입니다. 요청에 IP·목적지 필드를 임의 추가하지 않았습니다.
원본 가상 경보·src/decider.mjs·제작 3의 decide.mjs·다른 모듈을 보존했습니다. 공통 실행기 scripts/xdr-run.mjs에는 exfiltration의 applyRun 호출 조건 한 곳만 추가했습니다. step 12·허용 경로 7개·기존 RULE_IDS 6개는 유지합니다.

review-security 스킬은 제공된 스킬 목록과 로컬 스킬 경로에서 찾을 수 없어 해당 스킬 실행은 미실행입니다. 대신 응답 부품 코드를 직접 점검하고 위조/중복 근거·공유 정상 목적지·만료 경계·가상 규칙 운영 제외·기존 응답 및 규칙 이름 보존·안전 로그만 누적하는 시험 6개를 수행했습니다. 이를 해당 스킬 검토 완료로 보고하지 않습니다.
