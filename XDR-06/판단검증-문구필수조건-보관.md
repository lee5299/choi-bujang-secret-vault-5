# XDR-06 제작 3 — MITRE 기준 적용과 판단 검증

2026-10-16 사용자 요청: “MITRE가 정한 기준으로 해주세요.”, “근거는 MITRE ATT&CK T1041(명령 통로로 유출), T1048(다른 프로토콜로 유출) 입니다.”
초기 임의 수치 기준은 철회했습니다. 당시 결과와 이유는 [초기 기록](판단검증-초기기준.md)에 보관하며 현재 구현과 구분합니다.

## 공식 근거와 구현의 구분

- [T1041](https://attack.mitre.org/techniques/T1041/): 기존 명령·제어 통로와 같은 프로토콜을 통한 자료 유출. 명령 통로로 자료가 실제 전송됐다는 관찰을 대조합니다.
- [T1048](https://attack.mitre.org/techniques/T1048/): 기존 명령·제어 통로와 다른 프로토콜을 통한 자료 유출. 낯선 목적지·포트 변경을 프로토콜 관계로 대체하지 않습니다.
- 공식 탐지 지침은 비정상 외부 전송·업무 시간 밖·평소 대비 전송량 등의 조사 단서를 제시하지만 모든 환경 공통의 바이트·횟수·Wazuh 수준·확신도 임계값을 제시하지 않습니다. 50,000,000바이트·5회·수준 10 이상 조건을 코드와 현재 정책에서 제거했습니다.
- 확신도 0.85 이상 block, 0.5 이상 alert, 그 아래 record는 사용자 과제의 행동 경계입니다. 0.95(수법 관계와 자료 전송 근거), 0.6(의심 관찰), 0.5(관련 실패·미전송), 0.1(정상·불일치), 0(무효 입력)은 반환 형식에 맞춘 구현 값이며 MITRE가 매긴 확률·점수가 아닙니다.
- MITRE의 수법 정의를 차단 후보 근거로 사용하고, 수법 관계가 확인되지 않은 조사 단서는 alert에 남깁니다. 이 행동 배치는 이번 구현 선택이며 MITRE가 운영 차단을 명령하는 것은 아닙니다.

## 실제 코드 동작

patterns.json의 패턴 사본을 decide.mjs 맨 위에 그대로 내장하고 동기 decide(alert) 하나만 내보냅니다. import·파일·네트워크·환경변수 없이 단독 실행하며 입력을 변경하지 않습니다.
목적지·양수 bytes·전송 완료 표현·자료/파일 근거를 대조하고 T1041의 명령 통로 또는 T1048의 프로토콜 관계가 명시된 경우 block 후보입니다. bytes는 전송 유무를 뒷받침하는 값으로만 쓰며 크기 임계값으로 쓰지 않습니다. count·files로 전송량을 추정하지 않습니다.
규칙 수준은 가상 경보와 대조하고 읽기 출력에서 0~16 범위를 검증하지만 판단 점수·행동을 올리는 데 쓰지 않습니다. 실제 수법 근거가 같으면 수준 변경만으로 판단이 바뀌지 않습니다.
실패·취소·차단·미전송·프로토콜 관계의 부정/미확인은 성공한 수법 근거에서 제외합니다. 명령 통로라는 단어만 있거나 단순 heartbeat 전송만 있어도 자료 유출로 차단하지 않습니다.
명시적인 정상 백업·동기화는 record입니다. 관련 준비·부분 전송·실패는 조사 알림이며 유출 성공이 아닙니다. 업무 일정·평소 목적지는 시각·주소만 보고 추정하지 않습니다.

## 실제 검증과 이전 모듈 비교

모듈 9개·XDR 88개·전체 회귀 384개 통과, 실패 0개.
단독 파일 로드·제한된 실행 영역·동기 export 하나·패턴 사본 일치·입력 불변을 확인했습니다.
바이트·count·수준 변경만으로 MITRE 근거를 만들어내지 않는 시험, T1048의 실제 프로토콜 관계 긍정·부정·미확인, T1041의 소량 자료 전송, heartbeat·포트 변경·태그만의 부족 근거, 한국어·영문·실패·미전송·정상·무효 입력을 시험했습니다.
기존 XDR6의 50,000,000바이트·5회 경계 기대값과 원본 10/10/10 기대값을 이번 사용자 요청에 맞게 수정했습니다. 다른 모듈·이전 단계 시험 기대값은 변경하지 않았습니다.
privilege·persistence·known-cve와 동기 독립 판단, 불충분한 근거의 알림, 기존 입력/출력 보존 원칙은 같습니다. 이번 XDR6은 수법 정의로 확인할 수 있는 통로 관계를 차단 후보 조건으로 사용하며 다른 모듈을 일괄 변경하지 않습니다.

현재 동작은 지원한 설명 표현을 대조하는 오프라인 판단입니다. 모든 문장·로그 형식을 이해하거나 실제 전송·승인·프로토콜을 조회한 것은 아닙니다. 추가 운영 정보와 연결은 TODO의 미완료 범위입니다.
