트리거: 「작업정리」, 「문서 정리」, 단계 마감 문서 요청.
**현재 형식 기준은 `7/작업정리.md`** (XDR은 `XDR-02/작업정리.md`)입니다.
이번 주 작업이 끝나면 형식을 다듬을 예정입니다. 형식을 바꾸면 이 문서의 목차·그림 규칙을 먼저 갱신하고, 그 뒤 문서를 만듭니다.

## 범위

- 문서 작업에서는 프로그램·설정·데이터를 바꾸지 않고 서비스 시험·배포·bundle·심판 접수를 다시 실행하지 않습니다.
- 이전 결과를 인용할 때는 「당시 기록」임을 밝히고 커밋 해시를 붙입니다. 문서·그림 렌더링 확인만 새로 실행합니다.

## 그림 규칙

- 범례는 SVG 내부 우측 상단. HTML 설명으로 대체하지 않습니다.
- 배지: 신규 `#EAF7EE / #9FCDB0 / #276644`, 변경 `#EDF5FF / #AAC7E5 / #315A83`. 테두리 1px·반경 7px·글자 12px. 글자로도 구분합니다.
- 역할 색: 회색(기존 부품·실행·파일), 보라(기존 웹 서버), 황토(계약·미연결), 빨강(추가 확인 결정). 그림마다 실제 쓴 색만 범례에 둡니다.
- 시퀀스는 순서만 나타냅니다. 측정하지 않은 시간을 넣지 않습니다.

## 생성 도구 주의

`local-only/stage7-doc-qa/build-document.mjs`는 Codex 실행 환경 경로(`C:/Users/Administrator/.cache/codex-runtimes/…`)의 playwright·marked를 불러옵니다.
다른 도구에서는 그 경로가 없을 수 있으니 먼저 확인하고, 없으면 사용자에게 알립니다. 패키지 설치는 승인 후 `--no-save`로 하며 `package.json`은 바꾸지 않습니다.
