# 현재 구성

브라우저는 동일 출처의 로그인·기기 등록·메모·공지 API를 호출합니다. 서버는 로그인 후 승인 기기의 WebAuthn 요청 증명을 검사하고 기존 자료 소유자·강사 권한을 검사합니다. 기기 등록 성공은 pending이며 DB 관리자가 승인합니다. 매 보호 요청에 사용자·세션·일회용 확인값·method·경로·본문 지문을 결합합니다. 개인키는 운영체제 인증기가 관리하고 세션은 메모리에만 둡니다.
판정기는 운영 엔진이 확인한 기기·경로·신호로 접근을 판단하며, XDR-01·02는 오프라인 가상 분석입니다.

2026-10-14 사용자 결정으로 이전 Jev 연결 코드·시험 화면·관련 파일을 제거했습니다.
패키징 기준표의 /api/ai와 /api/threat-intel은 501을 반환하는 비활성 시작 틀입니다. 외부 AI 호출은 없습니다.
학생 서버 연결 계약은 docs/ACCESS_APP_CONTRACT.md, 공개 선언은 access-app.config.json에서 관리합니다. 빌드가 /access-app.json과 배포 /aleph.json의 accessApp을 생성합니다. 설정의 값으로 승인을 대체하지 않습니다. 실제 DB 적용·기기 인증·배포는 미실행입니다. 운영 심판 호환은 미확인으로 두고 사용자 지시에 따라 확인을 건너뜁니다.
