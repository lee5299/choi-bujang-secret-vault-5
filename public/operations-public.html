탈환 작전실

로그인 없이 확인하는 작전실 B입니다. 네 영역의 현재 상태와 확인 근거를 함께 봅니다.

실제 HTTP 응답과 가상 연습은 별개입니다. 운영 엔진과 연결되지 않은 영역은 「미연결」, 실행하지 않은 확인은 「미실행」으로 표시합니다. 기록 없음은 안전을 뜻하지 않으며, 이 화면의 문구는 심판 통과 근거가 아닙니다.

네 영역 요약

요약을 아직 불러오지 않았습니다(미실행).

    1~11단계 정상·금지 요청 시험 표

    공식 41종 시험과 별개의 재시험 목록입니다. 아직 실행하지 않은 공식 41종은 0/41 · 미실행으로 유지합니다. 가상 시험 통과는 실제 API 응답으로 넣지 않습니다.

    시험 표를 아직 불러오지 않았습니다.

    실측 환경별 요청 기록 — 출처 주소가 다른 결과는 합산하지 않습니다.

    로그인이 필요한 실측

    요청 행을 선택하고 자료실을 열어 직접 로그인 → 승인된 기기 확인 → 해당 요청을 실행하세요. 본문·계정 정보·인증 정보를 넘기지 않고 응답 메타데이터만 이 표로 연결합니다. 파일을 만들 필요가 없습니다.

    계정·시험대상은 사용자가 확인합니다. 같은 method·경로의 다음 실제 응답 한 건만 선택한 행에 연결하며 다른 행·환경으로 복사하지 않습니다. 화면 연결 실측은 현재 페이지에만 남고, 서버 기록 보관·로그 대조·배포 실측 완료를 뜻하지 않습니다.

    실제 API 응답에서 확인한 결과

    이 페이지에서 보낸 요청만 기록합니다. HTTP 상태·오류 코드·요청 ID·브라우저 확인 시각(UTC)을 보여 주며, 응답 본문과 메모 내용은 기록하지 않습니다. 같은 요청 ID의 서버 기록 vault_api_result와 대조하세요. 서버 로그 대조는 별도 확인입니다.

    이 버튼은 인증 정보 없이 메모 목록과 관리자 요약에 GET 요청을 보냅니다. 두 요청은 모두 401 login_required가 기대값입니다. 정상 사용자 접근·회수·복구 확인을 대신하지 않습니다.
