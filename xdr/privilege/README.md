## 제작 2 판단 기준과 근거

[MITRE T1068](https://attack.mitre.org/techniques/T1068/)은 소프트웨어 취약점 악용으로 권한을 높이는 수법입니다.
[MITRE T1078](https://attack.mitre.org/techniques/T1078/)은 정상 계정 탈취·악용을 설명합니다.
관리자 그룹 추가·낯선 명령·시간 밖 사용은 이 과제의 관찰 조건이며 그 자체로 두 기법을 확정하지 않습니다.
그룹 조회·일반 과제 그룹 추가·취소·실패·정상 관리자 작업을 구분하고 높은 수준이나 기법 표식만으로 회수 근거를 만들지 않습니다.
평소 목록이나 업무 시간표가 없으면 경보에 명시된 관찰만 사용하고 기준을 임의로 정하지 않습니다.

목록 확인 명령: `Get-Content xdr/privilege/patterns.json`.
편집기 **xdr → privilege → patterns.json → patterns**를 누릅니다.
정상: 세 패턴에 각각 이름·signal/require/exclude·evidence 한 줄·source가 있습니다.
검증 거부 대상: 빠진 근거·여러 줄 근거·요청 기법과 다른 출처. 이번에는 판단·차단을 실행하지 않았습니다.

## 제작 3 판단 기준과 다시 확인하기

이 절은 최초 제작 3 기준의 기록입니다. 이후 보완된 점수·수준 조건·검증 수는 위 최신 재검토 기록을 따릅니다.

확신도는 패턴의 관찰 신호가 얼마나 명확히 조합됐는지의 수업용 점수이며 통계적 악성 확률이 아닙니다.
0.85 이상 block, 0.5 이상 alert, 그 아래 record로 반환하며 반환은 action·confidence·reason 세 항목입니다.
reason은 패턴 이름 하나입니다. 맞는 패턴이 없을 때의 no_matching_pattern은 새 공격 패턴이 아닌 일치 없음 표시입니다.

- 관리자 그룹 추가와 같은 경보의 명령 실행, 다른 계정 권한을 이용한 실행, 명시적 취약점 악용과 권한 변화: 0.95.
- 낯선 주소/명령과 시간 밖 권한 사용의 조합: 0.9. 권한 변화와 명시적 낯섦의 조합: 0.85.
- 그룹 추가만 확인: 0.7. 시간 밖 권한 사용만 확인: 0.65. 낯선 명령·단독 권한 상승·실패/취소된 권한 시도: 0.5.
- 정상 또는 일치 없음: 0.1. 변화가 없거나 그룹 조회만 확인된 사건: 0.2. 설명 누락·형식 부족은 0.5로 확인 대상으로 남깁니다.

원본 26건의 함수 호출 결과는 block 6·alert 6·record 14입니다. 관리자 그룹 추가 하나, 여러 계정 추가, 재추가만 확인된 pv-01·pv-05·pv-09는 제작 2 조건에 따라 알림으로 남겼습니다.
평소 관리자 명령·일반 과제 그룹 변경·목록 조회와 로그인/로그아웃은 그 내용만으로 차단하지 않습니다.
정상 구간 마지막 9건은 모두 record이며 수준·MITRE 표식을 높여도 같습니다.
경보 간 상태·ID를 저장하지 않으므로 서로 다른 경보의 계정·시간을 자동 연계하는 기능은 없습니다. 한 경보 안에서도 서로 다른 user/admin 가상 계정의 신호는 조합하지 않습니다.
설명에 명시된 한글·영문 관찰 문구를 사용하며 실제 운영 기준 목록이나 계정 주체를 추정하지 않습니다.

실행: `node --test test/xdr-privilege.test.mjs`.
편집기 **xdr → privilege → decide.mjs** 맨 위 패턴과 아래 decide를 확인합니다.
정상 결과: 모듈 검증 9개 통과. 거부 확인: 명확한 조합은 block이며 정상·실패·취소·부정문을 성공한 공격으로 차단하지 않습니다.
